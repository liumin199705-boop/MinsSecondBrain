# Writing styles
Updated: 15 November 2026.

## Purpose
Maintain reusable writing preferences and examples in this repository so outputs can be refined consistently over time.
Start with legal-writing.md for legal drafting. Add separate profiles for other writing types only when needed.

## Learning from examples
When Min supplies writing she likes:
1. Identify the intended audience, purpose and document type.
2. Extract concrete rules for structure, tone, sentence construction, terminology, level of detail, citations and formatting.
3. Separate content she likes from style she likes; do not infer that example facts apply to her.
4. Demonstrate the proposed rules on a short representative passage.
5. Record her corrections and mark rules confirmed only when approved.
6. Retain only examples authorised for the repository's visibility, preferably anonymised.
Keep profiles concise. Current task instructions override default styles.
